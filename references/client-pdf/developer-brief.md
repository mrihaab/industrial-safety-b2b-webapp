# Ghulam Safety Hub — Developer Brief

**Project**: Safety equipment & workwear website for an import/export business (Pakistan-based, targeting local + international B2B buyers).  
**Design Status**: UI already designed (5 mockup pages attached as HTML). Build to match — don't redesign.

4. **Categories**: see category tree below
5. **Product Detail Page**: multiple images, description, specs, size/color options, inquiry button
6. **Inquiry / Quotation Form**: contact + product/quote requests, notify via email or WhatsApp

8. **Contact Us**: phone, email, address, Google Maps embed, contact form
9. **Admin Panel**: add/edit/delete products, upload images, manage inquiries, edit site content
10. **Fully responsive**: mobile, tablet, desktop
11. **Product search**
12. **Downloadable PDF catalog**
13. **Testimonials / reviews section**
14. **Social links**: Facebook, Instagram, LinkedIn, YouTube
